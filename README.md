# NU Academic Calendar 2026-2027

**Live Demo:** [View Academic Calendar](https://nu-academic-calendar-alpha.vercel.app/)

## Overview

A modern, interactive web application designed to help Nile University students track academic semesters efficiently. This project transforms a traditional, static Excel schedule into a dynamic and accessible user interface. It is built with a "Modern Classic" editorial aesthetic, prioritizing clarity and user experience over generic designs.

## Features

* **Interactive Timeline:** A structured, chronological view of all academic events.
* **Smart Filtering:** Instantly filter events by categories such as Exams, Holidays, Deadlines, and Registration.
* **Theme Toggle:** Seamless switching between light and dark modes for an optimal viewing experience.
* **Custom Assets:** Utilizes inline SVG icons to eliminate external dependencies and prevent rendering errors.
* **Admin-Controlled Data:** Event data is managed internally within the codebase architecture rather than exposed in static files, ensuring robust and centralized updates.
* **Responsive Design:** Fully optimized for both desktop and mobile platforms.

## Tech Stack

* **Frontend:** React
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **Deployment:** Vercel

## Local Setup

To run this project locally, execute the following commands in your terminal:

1. Clone the repository:
   ```bash
   git clone [https://github.com/MostafaSaber-25/nu-academic-calendar.git](https://github.com/MostafaSaber-25/nu-academic-calendar.git)
   ```

2. Navigate to the project directory:
   ```bash
   cd nu-academic-calendar/academic-calendar
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
